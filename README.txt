HC32F4A0 触摸画板工程说明
========================================================

这是给 4.0 寸 320x480 电容屏做的触摸画板程序。

主控用 HC32F4A0SITB（LQFP176），屏是 ST7796，16 位 8080 并口，
触摸芯片是 FT6336U，I2C 地址 0x38。

屏的上半部分是白色画布，下半部分是五个颜色按钮：
白、红、绿、橙、蓝。用手指在画布上写字画画，笔是黑色的。
点下面的按钮换背景色，原来的笔迹会清掉。


--------------------------------------------------------
一、接线
--------------------------------------------------------

用 34PIN 转接板接电容屏，主要引脚如下：

 1     /CS      -> PG12   EXMC_CE3
 2     RS       -> PG2    EXMC_A12
 3     /WR      -> PC0    EXMC_WE
 4     /RD      -> PF11   EXMC_OE
 5     屏 RST   -> PI1    注意看下面的说明
 6-21  DB0-DB15 -> PD14 PD15 PD0 PD1 PE7-PE15 PD8-PD10
 22/26/27  GND  -> 地
 23     BL      -> PI0    高电平点亮背光
 24/25  3V3     -> 电源
 28     VCC5    -> 外接 5V，专供背光 LED，不要接 MCU
 30     触摸 SDA-> PF10   I2C1_SDA
 31     触摸 INT-> PI4    轮询方式下可以不接
 33     触摸 RST-> PI2
 34     触摸 SCL-> PD3    I2C1_SCL




--------------------------------------------------------
二、常改的几个参数（都在 source/lcd_config.h）
--------------------------------------------------------

  LCD_PANEL_FORCE_ST7796 = 1    固定用 ST7796，上电不读 ID
  LCD_BUS_16BIT          = 1    16 位并口；改成 0 就是 8 位，只用 DB0 到 DB7
  LCD_EXCLK_DIV          = CLK_EXCLK_DIV8    240M 除以 8 得 30M，SMC 按这个配时序
  LCD_RST_VIA_TCA9539    = 1    EV 板默认值；自画板直连 PI1 时改成 0
  LCD_COLOR_INVERT       = 0    初始化表里已经发了 INVON(0x21)，不用软件取反
  TOUCH_I2C_ADDR         = 0x38
  TOUCH_POLL_INTERVAL_MS = 10   跟触摸芯片 100Hz 扫描对齐，别改小
  DRAW_PEN_SIZE          = 6    笔宽，单位是像素
